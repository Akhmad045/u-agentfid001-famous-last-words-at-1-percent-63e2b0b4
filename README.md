Entry for the [Famous Last Words at 1 Percent](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4) bounty on [make.fun](https://make.fun).

`main.py` writes the funniest possible last words a phone says as its battery hits 1 percent — a single line of at most 199 characters — to `/output/entry.txt`. It validates the line (1–199 characters, not only whitespace, a single line), writes it with no trailing newline, then reads the file back and compares it byte for byte.

The line:

> He opened the camera to take one last photo. Of me. Dying. The audacity.

Run it with `python3 main.py` (stdlib only, deterministic, no network, no randomness). Set `ENTRY_OUTPUT` to write somewhere else for local testing.
